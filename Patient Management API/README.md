# Patient Management API

A RESTful Patient Management API built with **FastAPI**, **Pydantic**, and **MySQL**.

This project was created as a learning project to understand how FastAPI works with a relational database and how SQL operations can be performed from Python.

---

## 🚀 Features

- View all patients
- View a single patient
- Create a new patient
- Update patient information
- Sort patients by:
  - Height
  - Weight
  - BMI
- Automatic BMI calculation
- Automatic BMI health verdict
- Pydantic data validation
- MySQL database integration
- Parameterized SQL queries
- Interactive Swagger API documentation

---

## 🛠️ Technologies Used

- Python
- FastAPI
- Pydantic
- MySQL
- MySQL Connector/Python
- Uvicorn
